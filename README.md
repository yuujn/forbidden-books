# Forbidden Books (Capstone Project, Week 4)
This is an accounting application produced by and for a fictitious organization
known by the name "Forbidden Merchandises LLC."

Do not actually use it! Seriously.

Without further ado, let's pretend this is all real.

## Forbidden Books
Welcome to our in-house accounting system!

It is very simple. Just open it up, and choose whether you'd like to...

...record a deposit.

...record a payment.

...open the ledger.

If you'd like to record a deposit or payment, the system will prompt you for
the information we need to retain. Just type that in, hit enter, and presto!
If something goes wrong, you'll be told the moment it happens, no losing unsaved work here!

### The Ledger
The ledger is where you go if you want to read about past transactions.

It supports listing any of the following:
- Every Transaction Ever Made
- Every Deposit Ever Made
- Every Payment Ever Made

...and, of course, there are other more fine grained reports you can request it to generate.
For those, you'll need to select the "Reports" menu option inside of the ledger.

Once you're in the Reports menu, you'll be able to select a report on any of the following:
- Month To Date
- Previous Month
- Year To Date
- Previous Year
- Search by Vendor
